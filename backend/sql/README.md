# SQL Directory — RescueGuard Backend

Pre-written, parameterized BigQuery SQL files for deterministic data operations, derived views, and vector search joins.

Per Part 2 line 651:
> BigQuery rules: core numbers use pre-written, parameterised SQL in `backend/sql/`, never string-concatenated user input. Free-form model SQL is allowed only for one-off read-only questions via the managed BigQuery MCP (`execute_sql_readonly` only), must show query + job ID, and must never feed ranking, matching, or impact.
